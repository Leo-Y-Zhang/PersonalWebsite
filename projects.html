Project notes

The projects and the evidence behind their results.

At a glance

There are 33 public repositories and 174 accepted OEIS terms across 21 sequences. The OEIS figure was re-derived on 3 November 2026. Over 3,700 automated tests were measured across the two main systems on 26 August 2026. The mathematics is on the home page, with the certificate.

Selected projects

MathRecords Python
The published combinatorics: SAT encodings, DRAT proof certificates, and a verification gate (verify_all.py, in CI) that re-derives every published value from scratch before it is quoted — the five new mixed van der Waerden values ride on it. The full story is on the home page.
Tilefish C++
A Scrabble engine in C++ using the standard library: move generation, Monte Carlo simulation, endgame solving and self-play training, with every shortcut checked against brute force. Its strength is measured, not asserted: logged matches under a neutral referee against the strongest public engines, MAGPIE and Macondo, with the opponents pinned to recorded versions and the results and their limits in the repository. Play it in the browser.
Production web application TypeScript, PostgreSQL, private
A live product with real users: row-level security, versioned migrations, staged deployments behind a manual production gate, and roughly 980 unit plus 85 end-to-end browser tests. The repository is private because it holds operational configuration, and the product is not named here; details on request.
Systematic trading research platform Python, private
A research platform with an immutable hash-chained event ledger, broker reconciliation with operator-gated resolution, a latched kill-switch battery, a supervised paper-trading deployment, and a browser operations terminal — 3,574 automated tests measured 26 August 2026, with mutation testing on the safety-critical seams. Every candidate strategy faces deflated-Sharpe and overfitting gates that default to rejection, and most fail: results are pre-registered before they run, and the status document is generated from the system, never typed.
ClimateMesh Python, Raspberry Pi
Climate early warnings from a two-person team: twenty sensing nodes scoring flood and heat risk 0–100 in real time on one Raspberry Pi, an explainable anomaly model, and honest data-source provenance — a reading is labelled hardware only when a physical sensor produced it. 236 automated tests (6 October 2026) and a one-command judge validation passing 5/5 (26 August 2026).

Team & competitions

EndeavourRacing TypeScript
The team's three web applications for STEM Racing 2026: public site, lap-timing and driver-performance tool, and a project, risk and budget dashboard.
Independent research manuscript June 2026
Sixty-two pages on network structure in equity markets: the framework is validated on synthetic data, and the empirical validation is specified but deliberately not yet claimed.

Everything else, one line each

Each of these exists to make a claim checkable rather than to assert it.

HartBeat Rust
An RV32IM RISC-V interpreter, tested against the architecture's official compliance vectors.
Ratified Lean 4
A machine-checked proof-checker development: the soundness argument lives in a proof assistant, not a comment. Written up as a preprint, aiXiv:2610.03288.
Splitbrain Go
Partition-tests a real key-value cluster and machine-checks the observed histories for linearizability; the checker is validated against a brute-force oracle.
GraphRecords Python
The frontier dynamic programs behind the board-graph OEIS terms — exact counts where brute force is O(2n²/2).
BishopVerify Python
An independent verifier for those counts — the published numbers are re-derived by different code before they are trusted.
CipherTool Python
A classical-cipher solver run on forty published National Cipher Challenge ciphertexts: all twenty-two with a published answer solved, the other eighteen recorded as unverified rather than solved, and none labelled strong while wrong.
GradForge Python
A reverse-mode autograd engine and a small GPT on top; every gradient is checked against finite differences.
PathTracer TypeScript
A deterministic Monte Carlo path tracer whose 278 tests validate the rendering physics, not just the code.
DeterministicRaft Python
Raft consensus under a seeded fault simulator; the five safety properties are checked after every step and any failure replays from its seed.
QuantumCompiler Python
A teaching quantum-circuit compiler whose optimisations and SWAP routing are proved correct by exact unitary equivalence.
QuantumClaimReferee Python
A finite-sample referee for quantum measurement claims: memory-robust CHSH p-values and default-deny verdicts.
EvalAssay Python
Splits a reported LLM benchmark score into measured capability and measured artifact, with exact Shapley attribution.
Understudy TypeScript
An AI interview simulator, v1 live.
ChessPuzzleForge Python
An offline mate-in-N generator; a bundled chess engine re-proves every puzzle before it is emitted.
Refute Rust
An independent DRAT and LRAT proof checker with no dependencies, and a browser playground where proof files never leave the tab.
MeltSim TypeScript
Melting, freezing and boiling from one enthalpy conservation law, benchmarked against the analytic Stefan solution; runs in the browser.
VisionCheckR JavaScript
A privacy-first vision self-check that runs entirely in the browser; nothing is uploaded. Not a medical device.
RadoRecords Python
2-colour Rado numbers for x12+…+xn2 = z2, carried from a(30) to a(60) with DRAT-certified refutations.
OEISHeadroom Python
Finds OEIS sequences that stopped where a brute force ran out of patience, then extends them, each gated on reproducing every published term first.
DiscrepancyRecords Python
A SAT campaign on Erdős problem #176 (OEIS A398541), with a cold verification gate that must pass before anything is claimed.
CycleRamsey Python
Three-colour cycle Ramsey numbers as SAT, with a measured account of how far one desktop machine gets.
PalindromicVDW Python
Palindromic mixed van der Waerden numbers as SAT, with the same measured account of its limits.
SuiteAudit Python
Finds the tests that cannot fail: tests that would stay green whatever the code did.
GreekScansion Python
Scans Greek dactylic hexameter and reports only what the metre itself settles.
LiberPrimusAnalysis Python
Cryptanalysis of the unsolved pages of Cicada 3301’s Liber Primus: not solved, but a reproducible toolkit and an exclusion ledger.
BoundarySeverance Python
A geometric permutation test for whether a political boundary bends a city’s road network.
ChessEditForge JavaScript
Renders vertical chess videos to MP4 entirely on the local machine, with no external assets.

Checks and evidence

  • Mutation testing checks the safety-critical paths.
  • Generated documents quote numbers from the systems they describe, with checks that fail when document and code disagree.
  • Research declares hypotheses and thresholds before it runs.
  • Repositories use secret scanning and dependency auditing.
  • Solver verdicts and proof certificates carry separate labels.
  • Private repository figures are dated measurements, and unfinished work is labelled unfinished.
